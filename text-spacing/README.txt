SKETSA TEXT SPACING 0.3.4
==========================

Target: Sketsa 9.1 / NetBeans 11.3 / JDK 11

0.3.4 keeps the stable dual-format property handling from 0.3.3 and restores
VectorCanvas.refresh() after DOMUtilities.updateProperty() so Batik/Sketsa
rebuilds the rendered text immediately.

NBM specification version: 0.3.4
