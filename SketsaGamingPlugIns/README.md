# Interactive / Gaming Sketsa Plug-ins

This group contains **Input**, **Physics** and **Audio**. They are separate Java/Sketsa SDK modules and communicate in exported browser runtimes through neutral Sketsa event/action contracts rather than direct Java dependencies.

Each plug-in has an independent, dockable, scrollable NetBeans window, complete English documentation and a prebuilt `.nbm`.

See the repository-level [`README.md`](../README.md) and [`BUILDING.md`](../BUILDING.md).
