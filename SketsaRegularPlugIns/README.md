# Regular Sketsa Plug-ins

SVG authoring modules for Sketsa 9.1. Each plug-in has its own English `README.md`, source project and installable `.nbm`.

All tools now open in independent, dockable, scrollable NetBeans windows and are also available from the **Window** menu.

See the repository-level [`README.md`](../README.md) and [`BUILDING.md`](../BUILDING.md).
